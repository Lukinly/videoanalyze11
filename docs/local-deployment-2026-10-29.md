# 2026-10-29 本地部署版本

本版本包含 macOS 原生本地部署入口、公开首页与账号弹窗、图文 AI 笔记，以及平台官方播放器。

## 启动

使用 Node.js 24+，在仓库根目录执行：

```bash
brew install postgresql@16 redis mailpit ffmpeg
corepack pnpm install --frozen-lockfile
cp .env.local.example .env  # 仅首次执行，保留已有配置
# 在 .env 中填写 Groq 与 LLM 配置
corepack pnpm local:dev
```

应用入口为 `http://localhost:5173`，开发邮箱为 `http://localhost:8025`。本地数据保存在 `.local/`，不随源码上传。完整依赖、平台工具安装与验证方式见 [本地运行与验证](local-development.md)。

首次管理员账号可通过以下命令创建，邮箱需要尚未注册，密码在终端交互输入：

```bash
corepack pnpm admin:create --email admin@example.com
```

## 本版行为

- 首页无需登录即可浏览产品预览与功能介绍，使用分析功能时打开登录弹窗。登录、注册、找回密码共用弹窗，关闭或登录后保留已选视频和输入链接。
- 首页以白色为底，在标题、按钮和局部预览区保留适量蓝紫色，减少大面积渐变与光晕。
- 每段 AI 笔记使用一个时间范围入口，配合原视频代表帧和正文。新分析在原片清理前保存截图，截图随笔记共同删除或到期；旧笔记可通过本地原片临时补图。
- 读取平台链接信息后即可显示官方播放器，分析工作台和笔记页也可页内播放。YouTube 使用官方 API 跳转并同步进度；B站保留分P，通过起始时间参数重新载入，当前不回传连续播放进度。
- 保留打开原视频入口。官方播放器受原站网络与外嵌权限影响；当前网络下曾出现部分媒体资源加载缓慢，尚未确认真实视频成功起播。播放器接口与跳转行为已通过模拟官方接口的浏览器测试，不等同于真实媒体完整播放验收。
- 本地运行同时支持 Anthropic Messages 与 OpenAI 兼容 LLM，包含时长探测、队列恢复、跨进程进度通知及隐私结果清理的修复与测试。
