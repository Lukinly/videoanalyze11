本次工作整理目录、历史和运行说明，以下问题保留为后续修复范围，不能把整合完成理解为完整运行验收通过：

3. API 提交数据库任务后才向 Redis 入队；队列失败会留下 `queued` 记录，重试请求不会重新入队。
4. SSE 订阅已有实现，但生产流程未调用进度发布，当前进度更新依靠前端轮询。

应针对实际 PostgreSQL 约束、Worker 组合入口和队列故障场景补充验证，再进行真实上传与平台链接端到端验收。
