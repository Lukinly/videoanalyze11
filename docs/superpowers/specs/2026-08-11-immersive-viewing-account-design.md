# 十一 videoanalysis 沉浸式观看页与个人中心设计

日期：2026-08-11

## 目标

重构登录后的前端信息架构，使主页只承担欢迎、上传和观看。视频上传并创建分析任务后，主页切换为沉浸式观看状态：左侧大尺寸播放器，右侧为独立滚动、可跳转并跟随播放进度的章节笔记与逐字稿。积分充值、积分记录和账号操作迁移到独立个人中心。

品牌名称统一显示为“十一 videoanalysis”，视觉采用用户确认的第二版蓝紫主题。

## 方案选择

采用“同一路径按工作状态切换”的方案：

- 未选择视频时，根路径展示精简欢迎区和上传入口。
- 上传完成后，根路径切换为沉浸式观看工作区。
- `/account` 展示个人中心。
- `/admin` 保留现有管理员页面。

没有选择以下方案：

- 独立 `/watch/:videoId` 路由：需要先增加视频列表、刷新恢复和按 ID 加载当前视频的接口，超出本次视觉重构范围。
- 保留现有长页面并只修改 CSS：无法解决播放器不够大、右栏内容分散和整页滚动的问题。

## 页面结构

### 顶部导航

- 左侧显示蓝紫品牌标记和“十一 videoanalysis”。
- 右侧显示可用积分、用户邮箱和“个人中心”入口。
- 观看状态下保持紧凑，不显示充值表单或积分流水。
- 个人中心提供返回主页和退出登录操作。

### 上传前主页

- 保留欢迎文案，但压缩视觉高度，优先突出上传动作。
- 页面只包含欢迎区、上传卡片和必要的分析进度反馈。
- 不再显示积分充值面板、摘要、章节、搜索或空白逐字稿卡片。

### 沉浸式观看状态

- 桌面端占满导航栏以下的可视高度，不依赖整页长滚动。
- 主体为双栏布局：左侧弹性占据剩余空间，右侧固定在适合阅读的宽度。
- 左栏显示文件名、分析状态、大尺寸 16:9 播放器和紧凑分析进度。
- 右栏包含固定标签栏、搜索框和独立滚动内容区。
- 窄屏改为播放器在上、标签内容在下，恢复自然页面滚动。

### 右侧标签

“章节笔记”为默认标签：

- 顶部显示整体 AI 摘要。
- 每章显示开始时间、标题、章节摘要和要点。
- 点击时间或章节内容跳转至章节开始时间。
- 播放时高亮当前章节。

“逐字稿”标签：

- 按时间顺序显示转写片段。
- 点击片段跳转至对应时间。
- 播放时高亮当前片段。
- 保留现有大于 500 段时的虚拟列表策略。

搜索框固定在右栏标签下方，继续复用现有搜索 API。搜索结果在当前右栏中展示，点击结果跳转视频。

## 播放同步

- `VideoPlayer` 通过 `onTimeUpdate` 向观看工作区报告当前播放秒数。
- 工作区根据章节起止时间和逐字稿起止时间计算当前项。
- 当前项变化时进行平滑滚动，使其进入右栏可视区域。
- 用户主动滚动右栏时暂停自动跟随，停止操作数秒后恢复。
- 内容点击只改变播放时间，不改变当前播放/暂停状态。

## 个人中心

个人中心 `/account` 包含：

- 当前积分余额。
- 充值申请表单。
- 积分流水和充值申请记录。
- 当前账号邮箱。
- 修改密码。
- 退出登录。

现有 `CreditsPanel` 的业务能力继续复用，但允许拆分或调整展示结构，使其适合完整页面，而不是观看页侧栏卡片。

## 视觉语言

- 主标题和品牌使用深靛蓝。
- 主要操作使用亮蓝到紫色的渐变。
- 时间戳、播放进度和可点击定位信息使用亮蓝。
- 当前章节、当前逐字稿和标签状态使用紫色或蓝紫渐变。
- 页面主体保持浅灰白背景，蓝紫只承担层级和状态强调，避免影响长时间观看。
- 视频舞台使用深色背景，保证各种宽高比视频都清晰可辨。

## 播放器无声问题

无声问题作为独立故障处理，不预设根因。实施前验证：

1. 浏览器中的 video 元素是否被静音、音量是否为零以及是否存在自动播放限制。
2. 播放 URL 返回的视频源是否包含音轨。
3. 原始上传对象和任何兼容性处理后的对象是否为同一媒体版本。
4. 浏览器是否支持该音轨编码。

修复应落在已证实的根因处，不通过默认强制自动播放或绕过浏览器媒体策略解决。

## 错误与空状态

- 上传和分析错误继续使用现有错误信息，不阻断个人中心访问。
- 摘要尚未完成时，章节笔记显示分析中空状态；逐字稿可在转写完成后独立显示。
- 搜索无结果时显示明确反馈。
- 播放 URL 或媒体加载失败时在播放器区域显示可理解的错误状态。

## 测试与验收

- 组件测试覆盖主页状态切换、标签切换、章节和逐字稿跳转、当前项计算、个人中心导航。
- 保留现有章节、逐字稿、摘要、积分和认证测试。
- 播放器测试覆盖时间上报以及经诊断确认的音频修复行为。
- 响应式验收覆盖宽桌面、普通笔记本和窄屏布局。
- 最终运行 Web 测试、全库类型检查、lint 和相关验收测试。

## 非目标

- 本次不新增视频历史库和刷新后恢复当前视频。
- 不修改分析、计费或摘要 API 的业务语义。
- 不新增富文本手写笔记编辑器；“笔记”指现有 AI 摘要、章节摘要和要点。
