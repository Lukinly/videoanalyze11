# “成长迷雾，如何找到自己的火花”插画设计

## 目标

为社交媒体文章制作两张互相呼应的竖版主视觉。画面讲述一个人在成长的迷雾中寻找内在火花的过程，情绪从迷惘过渡到微弱但确定的希望。

## 共同约束

- 竖版构图，适合作为社交媒体文章封面或配图。
- 画面不包含文字、标志、水印或边框。
- 人物为匿名的独行者，不突出具体身份、年龄或五官。
- 主体位于画面中下部，上方保留安静、低细节的标题空间。
- 火花是唯一明确的暖色视觉锚点；它应小而珍贵，不表现为熊熊大火。
- 迷雾具有层次和方向感，不能完全遮挡人物，也不能让画面失去清晰焦点。
- 最终画面需要在手机缩略图尺寸下仍能看清“人物—道路/雾—火花”的叙事关系。

## 方案一：电影感数字绘画

- 场景：幽蓝色的浓雾、隐约可见的崎岖路径与远方轮廓。
- 主体：一个背对观众、正在向前行走的独行者。
- 叙事：远处或人物前方有一簇橙金色微光，火光照亮一小段道路并在雾中形成柔和光束，暗示方向刚刚显现。
- 风格：高完成度电影概念艺术，写实而非照片，具有体积雾、景深和细腻环境纹理。
- 色彩：冷青、深蓝、炭灰为主，橙金色仅用于火花及其微弱反光。
- 情绪：孤独、克制、坚定；希望并不宏大，但真实存在。

## 方案二：东方水墨幻想

- 场景：大片泼墨般的山雾与若隐若现的路径，墨色从浓重混沌逐渐化开。
- 主体：一个简洁含蓄的行者，在雾中停步或缓慢前行。
- 叙事：人物掌心或胸前托住一点朱红火种，周围墨色被微光轻轻晕开，表现“先守住自己的光”。
- 风格：当代东方水墨幻想，结合宣纸渗化、飞白、干湿墨层次和少量电影式光影；不做古装海报感。
- 色彩：黑、灰、纸本暖白为主，只用一点朱红与微金表现火种。
- 情绪：空灵、沉静、内省；迷雾并未消失，但人物已有内在方向。

## 验收标准

两张图应拥有一致的核心隐喻，但在视觉语言上明显不同。第一张强调“看见并走向火光”，第二张强调“发现火光原来在自己身上”。两张均须具备清晰竖版层次、顶部标题留白、无文字和单一暖色焦点。
