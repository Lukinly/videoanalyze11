# “成长迷雾，如何找到自己的火花”插画设计

## 目标

为社交媒体文章制作两张互相呼应的竖版主视觉。画面讲述一个人在成长的迷雾中寻找内在火花的过程，情绪从迷惘过渡到微弱但确定的希望。

## 共同约束

- 竖版构图，适合作为社交媒体文章封面或配图。
- 画面不包含文字、标志、水印或边框。
- 人物为匿名的独行者，不突出具体身份、年龄或五官。
- 主体位于画面中下部，上方保留安静、低细节的标题空间。
- 火花是唯一明确的暖色视觉锚点；它应小而珍贵，不表现为熊熊大火。
- 迷雾具有层次和方向感，不能完全遮挡人物，也不能让画面失去清晰焦点。
- 最终画面需要在手机缩略图尺寸下仍能看清“人物—道路/雾—火花”的叙事关系。
- 人物具有平和、克制、自由的无兵刃游侠气质，以素色宽袖长衫、轻便披风和从容姿态表达；不出现长剑或任何武器。
- 降低大面积纯黑、阴冷压迫和危险感，让薄雾、留白与柔和光线带来舒适、温润的观看体验。

## 方案一：平和游侠电影感数字绘画

- 场景：清晨青灰与浅蓝色的薄雾山路、隐约可见的平缓路径与远方轮廓。
- 主体：一个背对观众、穿素色宽袖长衫与轻便披风、正在从容前行的无兵刃游侠。
- 叙事：远处或人物前方有一簇柔和橙金色微光，火光温暖地照亮一小段道路并在薄雾中形成轻柔光束，暗示方向刚刚显现。
- 风格：高完成度电影概念艺术，写实而非照片，具有体积雾、景深和细腻环境纹理。
- 色彩：青灰、浅蓝、柔和炭灰为主，橙金色仅用于火花及其微弱反光；避免大面积纯黑。
- 情绪：清寂、从容、坚定；希望并不宏大，但真实存在，画面令人平静而非紧张。

## 方案二：平和游侠东方水墨幻想

- 场景：大片泼墨般的山雾与若隐若现的路径，墨色从浓重混沌逐渐化开。
- 主体：一个身穿素色宽袖长衫与轻便披风的无兵刃游侠，在雾中安静停步或缓慢前行。
- 叙事：人物掌心或胸前托住一点朱红火种，周围墨色被微光轻轻晕开，表现“先守住自己的光”。
- 风格：当代东方水墨幻想，结合宣纸渗化、飞白、干湿墨层次和少量电影式光影；不做古装海报感。
- 色彩：浅墨、灰、纸本暖白为主，只用一点朱红与微金表现火种；增加纸白并减少浓黑面积。
- 情绪：空灵、温润、沉静、内省；迷雾并未消失，但人物已有内在方向，观感舒展平和。

## 验收标准

两张图应拥有一致的核心隐喻，但在视觉语言上明显不同。第一张强调“看见并走向火光”，第二张强调“发现火光原来在自己身上”。两张均须具备清晰竖版层次、顶部标题留白、无文字和单一暖色焦点。

## 横版电影感版本：丰富画面

- 编辑目标为 `assets/social/finding-inner-spark-cinematic-landscape.png`，保留原文件并另存新版本。
- 保留纤细无兵刃游侠、晨雾山路、远方小火光、横版构图、平和色调与整体视觉风格。
- 在人物与远方火光之间增加少量、疏密克制的橙金色微光颗粒，让火花沿道路穿过薄雾，强化“寻找自己的火花”的叙事。
- 在天空下缘增加两至三层极淡远山，并加入柔和晨光层次，丰富上半部但不形成抢眼主体。
- 顶部仍保留约三分之一低细节空间，方便后续添加文章标题。
- 不加入亭子、建筑、飞鸟、额外人物、武器或明显奇幻生物；不把火花处理成大面积光点或节庆灯饰。
- 验收时应同时满足：画面不再显得空、人物与远方火光仍是主叙事、整体依然平和舒展。
