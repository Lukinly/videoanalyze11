# 临时视频与解析结果保留策略设计

## 目标

网站不长期保存用户上传的原始视频和派生音频，同时保证用户关闭、刷新或离开页面后，后台解析任务仍能继续。普通解析的逐字稿、摘要和章节保存在用户账户中；用户可以导出或永久删除。另提供隐私解析模式，其文字结果仅临时保留 24 小时。

本设计替代项目此前“原视频默认保留 7 天、解析结果默认保留 30 天”的策略。

## 产品规则

### 普通解析

- 原视频只作为本次解析的临时输入，不作为在线播放或网盘资源长期保存。
- 任务进入 `completed`、`failed` 或 `cancelled` 后，立即安排删除原视频、抽取音频和音频分片。
- 逐字稿、摘要、章节、时间戳和必要的视频元数据保存在用户账户中，默认不自动到期。
- 用户可以随时导出解析结果，也可以主动永久删除某条解析记录。
- 用户关闭或刷新页面不取消任务。重新登录后可以查看任务进度或已完成结果。

### 隐私解析

- 原视频和派生音频遵循与普通解析相同的删除规则。
- 逐字稿、摘要和章节在任务完成后保留 24 小时，之后自动永久删除。
- 页面必须在创建任务前明确显示到期时间和“到期后不可恢复”的提示。
- 用户可以在到期前查看和导出结果，但不能依赖浏览器本地缓存延长服务端保留时间。

### 账号与计费数据

为保证账号安全、积分结算和审计，下列数据不随原视频或解析正文一起删除：

- 用户账号、认证和安全状态；
- 积分余额、不可变积分流水、充值及退款记录；
- 分析任务的标识、用户、视频时长、计费积分、最终状态和必要的错误分类；
- 删除时间、删除原因及不包含用户内容的清理审计信息。

任务审计中不得保存原视频、音频、完整逐字稿、摘要正文或可长期访问的对象存储 URL。文件名可能包含个人信息；结果删除后，历史账单默认只显示通用任务名称或经过清理的展示名。

## 数据存储

### 临时对象存储

MinIO 或兼容 S3 的对象存储只保存：

- 原始上传视频；
- 处理过程中需要跨进程传递的音频或分片；
- 尚未写入数据库的临时结果文件。

所有对象必须携带所属用户、分析任务、数据类型和绝对到期时间。正常路径在终态后立即删除；异常路径由定时清理任务兜底。任何临时对象从上传完成起最长不得保留超过 24 小时，仍在正常运行且心跳有效的任务除外；有效任务也必须受独立的最大任务运行时长约束，不能无限续期。

这里的“对象存储”分为两个部署阶段：

- 当前阶段继续使用项目现有、由本站服务器管理的临时媒体存储。浏览器上传仍经过本站服务，不要求接入阿里云 OSS、腾讯云 COS、Cloudflare R2 等第三方私有对象存储。
- 后续流量或并发增长时，可以升级为云端私有对象存储直传。该升级是可选项，不是当前上线前置条件，也不得在未重新确认供应商、地区、价格和隐私条款前实施。

### 可选升级：私有对象存储直传

预计出现 5 至 20 人集中上传、大文件上传频繁挤占服务器连接或本地临时磁盘不足时，可以评估启用直传：

```text
浏览器 -> 向业务 API 申请限时上传凭证
浏览器 -> 使用凭证将视频直接上传到私有对象存储
浏览器 -> 通知业务 API 上传完成并创建解析任务
worker  -> 从私有对象存储读取媒体并执行解析
worker  -> 结果可靠保存后立即删除媒体对象
定时清理 -> 最迟 24 小时删除异常残留对象
```

升级后的安全和产品边界如下：

- 存储桶必须为私有，不能提供永久公开 URL；业务 API 只签发短时、单对象、权限最小化的上传或读取凭证。
- 浏览器应使用分片上传和断点续传；业务服务器只负责鉴权、积分检查、任务创建和签名，不中转视频字节。
- 视频上传完成并进入后台队列后，用户可以关闭页面；重新登录后从“我的任务”查看进度和结果。
- 正常完成、失败或取消后立即清理原视频、派生音频和分片；对象存储生命周期规则以 24 小时作为异常兜底。
- 直传仅改变临时媒体的传输与保存位置，不改变“不长期保存用户视频”、结果保留、积分结算和用户主动删除规则。
- 正式接入前需要单独确认供应商、服务地区、存储费、请求费、流量费、跨境与合规要求，并补充端到端测试和故障回退方案。

暂不接入直传时，需要接受以下限制：视频上传仍占用本站入口连接和临时磁盘；高峰期必须通过上传并发限制、磁盘水位保护和任务队列保护当前 2 核 4 GB 服务器。对象存储直传记录为容量升级路径，不提前增加现阶段的学习和运维成本。

### PostgreSQL

PostgreSQL 是以下数据的唯一可信来源：

- 用户、会话、权限、积分和审计；
- 视频元数据和分析任务状态；
- 普通解析的逐字稿片段、摘要、章节及时间戳；
- 隐私解析结果的到期时间和清理状态。

浏览器 IndexedDB 或内存状态只能作为体验缓存，不能作为积分结算、任务状态或用户结果的唯一数据源。

### 备份

- 数据库每天生成加密备份，并保存到当前服务器之外的独立存储位置。
- 备份不包含原视频、音频和分片。
- 普通结果可以进入数据库备份；隐私解析正文原则上不得进入保留期超过 24 小时的常规备份。如果现有备份机制无法做到这一点，隐私解析正文应使用独立、可按期清除且不进入长期备份的存储方案。
- 需要记录和定期演练数据库恢复，但恢复流程必须再次执行到期清理，避免让已过期隐私结果重新可见。

## 任务与清理流程

```text
浏览器上传原视频
  -> 创建后台分析任务
  -> worker 下载临时原视频
  -> 提取音频并切片
  -> Groq 转写
  -> DeepSeek 生成摘要和章节
  -> 事务性保存文字结果与任务终态
  -> 删除原视频、音频和分片
  -> 用户稍后登录查看或导出结果
```

关键顺序是“结果可靠保存并提交事务”早于“删除原视频”。如果结果写入失败，任务进入失败状态，释放或按既定规则结算积分，然后仍要清理媒体对象。

关闭页面只会断开 SSE 或轮询连接，不向 worker 发送取消信号。只有用户明确点击“取消解析”时才进入取消流程。

## 删除语义

### 媒体清理

- 终态清理必须幂等；对象已经不存在应视为成功。
- 删除失败不能把已经成功的解析任务改回失败，但必须记录待重试状态。
- 定时任务持续重试删除，并对超过 24 小时仍未删除的对象产生告警。
- 本地 `/tmp` 工作目录在 worker 的成功、失败、取消和进程退出恢复路径中清理。

### 结果删除

- 用户主动删除普通解析结果后，正文、章节、搜索索引和相关对象不可再通过产品接口读取。
- 隐私解析到期执行同样的正文和索引删除流程。
- 删除采用可审计但内容最小化的方式：保留计费流水和任务状态，不保留被删除正文。
- 搜索索引必须和正文处于同一删除事务或具备可靠的补偿任务，不能返回已删除片段。

## 用户界面与文案

上传区域必须说明：

> 原始视频仅用于本次解析，任务结束后自动删除。关闭页面不会中断解析，稍后登录仍可查看进度和结果。

普通解析结果页必须提供“导出”和“永久删除”入口。删除操作需要二次确认，并明确结果不可恢复。

隐私解析必须额外说明：

> 隐私解析结果仅保留 24 小时，请及时导出；到期后逐字稿、摘要和章节将永久删除。

历史任务在原视频删除后不得展示失效的视频播放按钮。用户可以重新选择本地原文件进行本地播放，并使用已保存的时间戳定位；本地文件不得因此重新上传或触发新的解析收费，除非用户明确创建新任务。

## 容量与运行保护

针对当前 2 核、4 GB 内存、70 GB 系统盘和 600 GB/月流量的服务器：

- 单用户同时运行任务保持 1 至 2 个，全站 worker 并发初期保持 2；
- 临时媒体空间达到预警线时停止创建新上传会话，不影响查看已有文字结果；
- 建议临时媒体使用量在可用磁盘的 70% 告警，80% 拒绝新上传，并保留系统、数据库和清理操作所需空间；
- 上传失败、未创建分析任务和 worker 崩溃产生的孤儿对象必须纳入 24 小时兜底清理；
- 不通过保存原视频提供历史在线播放，以降低磁盘和下行流量成本。

## 错误与积分处理边界

- 页面退出不属于取消或失败，不退款，也不重复扣费。
- 任务创建和积分预留必须幂等，刷新或重复点击不能生成重复扣款。
- 未调用付费模型即失败或取消时，释放全部预留积分。
- 已产生 Groq 或 DeepSeek 成本后的取消、失败和退款比例由独立的积分结算规则决定；本设计不改变该规则。
- 媒体清理失败不向用户重复收费，也不阻止已经成功保存的结果交付。

## 验收标准

1. 用户上传后关闭页面，后台任务继续；重新登录能看到同一任务和结果。
2. 普通任务成功、失败或取消后，原视频、音频和分片均被删除，文字结果按规则保留。
3. worker 在终态清理前崩溃时，定时清理可在 24 小时内删除孤儿媒体。
4. 隐私解析结果在完成 24 小时后无法通过详情、搜索、导出或旧链接读取。
5. 用户主动删除普通结果后，正文、章节和搜索索引不可读取，但积分流水仍可审计。
6. 对同一对象或结果重复执行清理不会报错或破坏其他用户数据。
7. 临时空间达到硬限制时拒绝新上传，并向用户返回可重试的容量提示。
8. 数据库恢复后会重新清理已经到期的隐私结果。
9. 日志、错误和审计记录不包含 API Key、完整预签名 URL、原始媒体内容或完整解析正文。

## 不在本设计范围内

- 永久保存或在线播放用户原视频；
- 仅依赖浏览器保存解析结果；
- 自动支付、充值套餐和积分单价；
- 已产生第三方 API 成本后的具体退款比例；
- 将普通解析结果永久归档到低频对象存储。
