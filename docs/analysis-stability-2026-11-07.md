- 失败任务：`52949bc3-9054-45a7-9871-6a2e3787b781`。
- 来源：B站 `BV1oWPYzSEQK`，约 17 分 23 秒。
- 阶段：`transcribing`，进度 `0.55`。共 10 块，索引 0–4 已完成，索引 5（560–680 秒）停在 processing。
- 数据库错误：`Qwen ASR response omitted valid segments`。这表示服务返回了 JSON，但未通过 segments 结构校验；原始响应未保存，不能据此推断其具体内容。
- 在同一服务器、同一模型下重新下载并转写同一片段，成功得到 20 个有效片段。因此本次属于偶发的模型输出结构异常，下载、FFmpeg 与接口访问本身可用。

现有代码将这种输出异常与请求参数错误一起归为 `invalid_request`，因此完全不重试，直接终止整段视频。视频越长，请求次数越多，遇到一次异常即整段失败的概率越高。

## 修复

1. 用独立错误类型区分“模型输出无效”与“请求被拒绝”。缺少 segments、无效时间戳、JSON 错误及输出截断允许有界恢复；鉴权、参数、内容检查及额度错误维持立即失败。
2. ASR 每块最多请求三次，仅重试当前块，保留已完成块。仍输出异常时只把该块二分，每半块各最多三次；不递归二分，不保存半份结果，全部失败仍正常退款与清理。
3. 摘要和笔记的临时网络、429、5xx 错误统一退避重试，最多三次；无效模型输出最多重试一次。移除摘要外层的无条件重试，避免重复鉴权请求或倍增重试。
4. 模型请求超时覆盖读取响应正文的全过程，并传递分析取消信号。
5. 中文等非 ASCII 文本按更保守的 token 预算切窗；同一个任务逐窗处理，避免长视频同时发出大量 LLM 请求。
6. 新增 `asr_chunk_recovery` 和 `analysis_terminal_failure` 安全日志，包含任务、分块、阶段、错误分类，不包含原始响应、转录、音频 Base64 或密钥。通用模型 HTTP 错误也不再保存响应正文。
